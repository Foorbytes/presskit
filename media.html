Descriptions

Short studio description

Foorbytes is a one-person indie game developer creating offbeat PC and mobile games built around unusual subjects and memorable player decisions.

Short game description

Bad Credit? No Problem! is a paperwork simulation set inside a predatory title loan office. Review applications, follow changing rules, survive a demanding boss, and decide what happens to the people waiting across the desk.

Long game description

In Bad Credit? No Problem!, players work a 14-day probation period at Title 4 Cash, reviewing loan applications against an evolving rulebook. Correctly processing paperwork may keep the job, but every approval or denial can affect the applicant on the other side of the desk. The game combines pixel art, dark humor, office ambience, story-driven applicants, and Endless Shift after the main probation story is complete.
